# Directorio de Vistas / Componentes (src/views)

Este directorio está destinado a almacenar plantillas HTML reutilizables, parciales o componentes de interfaz Vanilla para la aplicación:

- **Componentes modulares:** Plantillas de modales, alertas dinámicas, widgets y fragmentos de navegación.
- **Páginas de la aplicación:**
  - `index.html`: Enrutamiento / redirección inicial.
  - `login.html`: Autenticación y registro de usuarios.
  - `productos.html`: Gestión de inventario de productos.
  - `clientes.html`: Consulta y directorio de clientes.
  - `pedidos.html`: Consulta y gestión de pedidos.
